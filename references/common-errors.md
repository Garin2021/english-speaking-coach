# 中文母语者英文口语常见错误速查

识别口语文本问题时对照本表检查。覆盖口语场景最高频的错误类型。

## 1. 中式直译（Chinglish）

逐字翻译中文思维，语法可能没错但英语里不这么说。

| 常见说法 | 问题 | 地道表达 |
|---|---|---|
| open/close the light | 动词误用 | turn on/off the light |
| I very like it | 副词位置 | I like it a lot / I really like it |
| I think it's not good | 否定转移 | I don't think it's good |
| the price is very expensive | 主语搭配 | the price is very high / it's very expensive |
| my English is not good | 生硬 | my English isn't great / I'm still working on my English |
| I with my friend went... | 语序 | My friend and I went... / I went with my friend |
| learn knowledge | 搭配 | gain/acquire knowledge |
| contact with sb (动词) | 多介词 | contact sb |
| I'm very like... | 词性 | I really like... |
| according to my opinion | 混搭 | in my opinion |
| how to say? | 直译 | How do you say...? / What's the word for...? |
| I very miss you | 副词 | I miss you a lot / I really miss you |
| the weather is very comfortable | 搭配 | the weather is lovely/nice |
| play with phone | 搭配 | be on my phone / scroll through my phone |
| I have a question to ask you | 冗余 | Can I ask you something? |

## 2. 时态

口语讲过去的事最容易出错。

- 叙述过去经历时，整段应统一用一般过去时；只有引用当时想法/感受才可能用过去进行时或 could。
- 时间状语（yesterday / last week / when I was... / a few days ago）后必须用过去时。
- 描述持续到现在的经历用现在完成时（have done），不要和过去时混用。
- 习惯性动作：used to do（过去常做，现在不了）vs. would do（过去常常）。
- 口语常见错误：*I go to the store yesterday* → I went；*I have seen it yesterday* → I saw it yesterday。

## 3. 冠词（a / an / the）

中文没有冠词，是最容易漏的一类。

- 单数可数名词不能裸奔：*I have question* → I have a question。
- 特指（双方都知道的那个、上文提过的、被定语限定的）用 the。
- 泛指一类事物用复数或 a/an：*I like the coffee*（指某杯）vs. *I like coffee*（泛指咖啡）。
- 抽象概念、泛指物质名词通常零冠词：*the life is hard* → life is hard。
- 固定搭配例外：go to school（上学）vs. go to the school（去那所学校）。

## 4. 单复数

- 不可数名词不能加 s：information / advice / news / feedback / research / equipment / furniture / luggage / money / time / work / homework / traffic。错误：*informations*、*advices*。
- many + 可数复数；much + 不可数。
- people 本身就是复数（a person / two people，不用 *peoples* 指"人"）。
- "人们"在口语里常用 people / folks，不用 *persons*。

## 5. 介词与动词搭配

高频固定搭配错误：

| 错误 | 正确 |
|---|---|
| discuss about sth | discuss sth |
| marry with sb | marry sb |
| emphasize on sth | emphasize sth |
| return back | return |
| repeat again | repeat |
| listen music | listen to music |
| participate in（正确）/ participate（需 in） | participate in |
| consist of（不用 by） | consist of |
| complain about/of | complain about |
| different with | different from |
| similar with | similar to |
| interested on | interested in |
| good in | good at |
| afraid from | afraid of |
| depend of | depend on |
| in the weekend | on the weekend / at the weekend |
| in Monday | on Monday |
| at home（不用 in home） | at home |

## 6. 词性误用

- 形容词/副词混淆：*I feel happily* → I feel happy（feel 是系动词，接形容词）。*He is a carefully person* → careful person。
- very 修饰形容词/副词，不修饰动词：*I very like* → I really like / like it a lot。
- hard（adj./adv. 努力）vs. hardly（几乎不）。
- 名词误作形容词：*a beauty place* → a beautiful place。

## 7. 主谓一致与第三人称

- 第三人称单数现在时动词加 s：*He like* → He likes；*She don't* → She doesn't。
- there be 就近原则：There is a book and two pens；There are two pens and a book。
- 集合名词（family / team / staff）在美式英语里通常作单数。

## 8. 句子结构

中文里成对出现的连词，英文不能连用：

- *Because... so...* → 只保留 because 或 so：Because it rained, we stayed home. / It rained, so we stayed home.
- *Although... but...* → 只保留 although 或 but：Although it was late, we kept walking. / It was late, but we kept walking.
- 缺失主语：中文常省略主语，英文必须有。*Is raining* → It's raining。
- 缺失系动词：*He very tall* → He is very tall。
- 悬垂分词/逻辑主语不清：*Walking in the park, the flowers were beautiful* → Walking in the park, I saw beautiful flowers.

## 9. 代词与指代

- he / she 混淆（中文口语里"他/她"同音，英文必须区分）。
- it / they 单复数混淆。
- 指代不清：一句里多个 this / it，读者不知道指谁——改成具体名词。

## 10. 口语自然度：书面 → 口语

口语纠错的目标是"说话自然"，不是"作文漂亮"。把过于书面的表达降为口语：

| 过于书面 | 口语自然 |
|---|---|
| I would like to inquire whether... | I was wondering if... / Can I ask... |
| It is of great importance | It's really important |
| I am of the opinion that | I think |
| utilize | use |
| purchase | buy |
| in the event that | if |
| nevertheless / moreover（口语少用） | but / also / plus |
| I deem it necessary | I think it's necessary |

同时，口语里这些是**自然且允许**的，不应标为错误：
- 碎片句、省略句（"Nice day." "Really?"）
- 重复、自我修正（"I mean...", "you know"）
- 用 like / basically / actually 作语气填充
- 缩读（gonna / wanna / gotta，视场景而定）

## 使用建议

按 1→10 顺序扫描全文，重点检查 2（时态）和 3（冠词），这两类是中文母语者口语中出现频率最高、最影响理解的问题。发现同一类错误反复出现时，在诊断末尾单列一条"整体提醒"而不是逐条重复。
